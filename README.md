# Reverse Engineer

- This tool is currently in its earliest stages.
- The whole point of this tool is to make reverse engineering older apps and older games more efficiently with the purpose of recovering code from abandoned games to make them run on newer devices with latest code and compatibillity, modding games and game logic
- I've noticed every time I try to mod a game's exe, I have to do alot of manual steps to just get the basic information, so why not globalize the logic.

no two apps are the same, however teh internal structure of an exe is somewhat consistent. Some exe's even have paths stored internally, linked to machine language in the exe (especially older titles when they didnt strip original file paths), so why not recover the exe as much as possible back into source code?
